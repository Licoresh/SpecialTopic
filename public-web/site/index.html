Methodology

Cleaning and counting

The public analyzer calls the same Python research cleaning, extraction, chart eligibility, job-profile, geography, alignment, gap, and PSF-AAI functions. Source IDs use the uploaded file hash and source row. Duplicate rows remain unless a researcher has reviewed and removed them in the active study dataset.

Classifier and public review scope

Public analysis uses the research classifier for uploaded phrases. Researcher-only saved labels, mapping reviews, and corrections are not applied to anonymous uploads.

Session storage

The browser can restore a dataset and results after refresh in the current tab. Use Clear session to remove the current dataset immediately. Cached copies expire after 12 hours and are removed on a later visit.
